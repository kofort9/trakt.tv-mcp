# Security Policy

## Reporting a Vulnerability
- Please **do not open public issues** for security problems.
- Use GitHub’s private advisory form: https://github.com/kofifort/trakt.tv-mcp/security/advisories/new
- If the advisory form is unavailable, contact the maintainers privately via GitHub (or email if listed in their profile).

We will acknowledge reports promptly and provide status updates until resolution.

## Supported Versions
- `main` and the latest tagged release are supported for security fixes.

## Handling Sensitive Data
- Do not include tokens, credentials, or personal data in issue reports or PRs.
- Logs and screenshots should be scrubbed of any secrets before sharing.
